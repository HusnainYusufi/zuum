What gets sent to Agent

When a form is submitted, the following data structure is sent to the Agent voice service:

Metadata & Dynamic Variables

{
  "form_number": "1",  // Form type identifier
  "form_title": "At Pickup Check-In",
  "purpose": [         // Voice questions array
    "Has the driver arrived at the pickup location?",
    "Is the driver empty and ready to load?",
    "What type of driver is this?"
  ],
  "form": {           // All form field values
    "load_id": "LD123456",
    "contact_phone": "+1234567890",
    "trucker_name": "John Doe",
    "pickup_address": "123 Main St",
    // ... other form fields
  },
  "output_schema": {  // Expected response structure
    "type": "object",
    "properties": {
      "Driver_empty": { "type": "boolean" },
      "Current_location": { "type": "string" }
      // ... other expected fields
    },
    "required": ["Driver_empty", "Current_location"]
  }
}

Complete API Payload

{
  "from_number": "+1XXXXXXXXXX",     // Your Agent phone
  "to_number": "+1234567890",        // Driver's phone
  "override_agent_id": "agent_xxx",  // Your agent ID
  "metadata": {
    // Same data as dynamic variables
  },
  "agent_variables": {
    // Same data structure
  }
}

How it works

  • The form_number helps the agent identify which form type is being processed
  • The purpose array contains the voice questions that guide the conversation
  • The form object contains all the submitted form data for reference
  • The output_schema defines the expected structure of data the agent should return after the call
  • Both metadata and agent_variables receive the same data
